Rocky Mountain National Park High-Res Forecasts

And other sundry odds and ends I'm interested in

What this site shows

This dashboard displayss high resolution (333m temperature and wind; 1km everything else) forecasts for Rocky Mountain National Park (333m resolution) and the surrounding area (1km resolution). Surface Map tab: 2m Temperature (fill); 10m Wind (arrows); Simulated composite radar reflectivity (contour); Precipitation type (dots) Lightning and Clouds tab: Vertically summed cloud cover (fill), hover over the map to see cloud cover percentage at each layer of the atmosphere at that point; Lightning Potential Index after Lynn and Yair 2010 (contour). Point forecasts: Meteograms of points of interest within Rocky Mountain National Park Verification: Comparison of yesterday's forecast to observations and the 333m high resolution dynamical forecast run

Methodology

A machine learning model is used to produce the surface temperature and wind forecasts on the inner domain. This model is trained using WRF forecasts of this grid as target data, and data from the 1km run as input data. For the rest of the data, the 1km WRF weather model run is used. Lightning Potential Index is displayed after going through maximum and gaussian filters to account for the fact that lightning can travel many miles from where the strike originates.

Limitations

1. The current model is running on well out of season training data - fix coming soon 2. The machine learning model is designed to provide forecasts for remote locations with unique microclimates due to steep terrain. Due to a lack of observations in these areas, the model is predicting the result of a higher resolution WRF run, rather than direct observations. This means that systemic model biases that show up at both 1km and 333m grid spacing will not be corrected for by the machine learning model. The machine learning model results are a downscaled version of the 1km forecast, not an independent forecast in and of themselves.
