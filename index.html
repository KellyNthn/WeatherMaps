Welcome to Weather Maps

This site hosts interactive 3D weather visualizations generated from WRF (Weather Research and Forecasting) model output for the Colorado Front Range.

Each map shows simulated atmospheric trajectories and wind patterns rendered as animated 3D trails. Use the controls inside each map to play, pause, and scrub through time.

Select a map from the navigation bar above to get started. Use the D-pad to pan or orbit the 3D scene on touchscreens.
